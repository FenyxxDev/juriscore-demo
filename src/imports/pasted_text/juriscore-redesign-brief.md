REDESIGN VISUAL COMPLETO DO JURISCORE — PRESERVAR FUNCIONALIDADE E FLUXO

Reformule visualmente todo o projeto JurisCore existente.

IMPORTANTE:

* NÃO criar novas telas.
* NÃO remover telas existentes.
* NÃO alterar a jornada do usuário.
* NÃO alterar a arquitetura da informação.
* NÃO alterar os fluxos, funcionalidades ou componentes necessários.
* NÃO simplificar o sistema.
* NÃO transformar o projeto em um dashboard genérico.
* MANTER todas as telas, informações, ações, navegação e fluxo já definidos.
* Alterar SOMENTE a direção de arte, identidade visual, composição, tipografia, espaçamento, proporções, tratamento dos componentes e acabamento visual.

O objetivo é fazer o JurisCore parecer um produto desenvolvido por uma empresa internacional de tecnologia especializada em software enterprise, com uma equipe experiente de Product Design, UX, UI e Brand Design.

O resultado NÃO deve parecer um template de Figma, um SaaS genérico ou uma interface gerada automaticamente por IA.

Deve parecer um produto digital real, maduro, sofisticado e cuidadosamente desenhado.

==================================================

1. DIREÇÃO DE ARTE
   ==================================================

Criar uma identidade visual própria para o JurisCore.

A referência deve ser:

* enterprise software premium;
* tecnologia jurídica sofisticada;
* confiança;
* precisão;
* inteligência;
* organização;
* sobriedade;
* alta qualidade editorial;
* design corporativo internacional contemporâneo.

O visual jurídico NÃO deve usar clichês como:

* balança de justiça;
* martelo de juiz;
* colunas de tribunal;
* fotos genéricas de advogados;
* prédios jurídicos;
* documentos antigos;
* imagens de banco de imagens.

Também NÃO usar elementos decorativos apenas para preencher espaço.

A interface deve parecer construída a partir de uma identidade de produto própria.

==================================================
2. EVITAR APARÊNCIA DE IA
=========================

Evitar deliberadamente os padrões visuais típicos de interfaces geradas por IA:

* excesso de cards;
* excesso de bordas arredondadas;
* excesso de sombras;
* gradientes genéricos;
* glassmorphism;
* excesso de badges;
* excesso de ícones;
* elementos perfeitamente distribuídos de forma artificial;
* excesso de simetria;

* componentes grandes demais;
* tipografia genérica;
* tudo transformado em card.

Usar composição mais sofisticada e intencional.

Nem toda informação precisa estar dentro de um card.

Utilizar:

* divisórias;
* agrupamentos tipográficos;
* hierarquia espacial;
* linhas sutis;
* áreas de destaque;
* tabelas densas;
* módulos;
* painéis;

* contêineres quando necessários.

5. TIPOGRAFIA
=============

Criar uma hierarquia tipográfica muito mais refinada.

Usar Inter ou uma tipografia sans-serif de nível editorial semelhante.

Não usar títulos enormes.

Priorizar:

* pesos tipográficos;
* tracking;
* altura de linha;
* contraste entre títulos e metadados;
* números importantes;
* microtipografia.

Números de processos, datas e indicadores devem possuir tratamento visual preciso.

Exemplo:

0001234-56.2026.8.17.0001

deve parecer um identificador importante, e não apenas texto normal.
